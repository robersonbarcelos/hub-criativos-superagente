# Hub de Criativos - Super Agente de IA

Hub interno de aprovação de roteiros de vídeo (criativos) para o produto Super Agente de IA.

Organiza os roteiros por formato — Caixinha de Pergunta, Selfie React, Tela Dividida, Talking Head —
cada formato com seus roteiros aprovados como sub-itens navegáveis.

## Deploy

Página estática única (`index.html`), sem build step, sem dependências além de fontes do Google Fonts.
Aponte Cloudflare Pages / Vercel / GitHub Pages pra raiz deste repositório — nenhum comando de build necessário.

## Conteúdo

Gerado via Claude Code a partir de roteiros escritos com a skill `video-script-sms`
(Master Social Design System), aprovados antes de entrar aqui.

Espelho deste conteúdo também vive em [`IntusHub/intus`](https://github.com/IntusHub/intus/tree/main/apps/hub-criativos-superagente).
